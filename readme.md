# Crypto Whale Tracker (Real-Time Dashboard)

โปรเจกต์สำหรับฝึกฝนพัฒนาทักษะ Software Engineering พัฒนาด้วย **GO** และ **React** 
โดยเน้นการเรียนรู้ไปที่ Real-time Data Streaming, Concurrency และการต่อยอดต่อไป

## เทคโนโลยีที่ใช้ในโปรเจกต์นี้
- **Backend:** Go (Golang) + WebSockets
- **Frontend:** React (Vite) + Tailwind CSS + Recharts
- **Database:** PostgreSQL (Future Phase)
- **DevOps:** Docker & Docker Compose (Future Phase)
